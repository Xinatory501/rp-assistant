# RP Assistant Flutter

Переписанная версия RP Assistant на Flutter (Windows Desktop).

## Требования

- Flutter 3.x (Windows Desktop support)
- Windows 10+

## Установка Flutter

1. Скачайте Flutter: https://docs.flutter.dev/get-started/install/windows
2. Добавьте flutter/bin в PATH

## Сборка релиза

## Горячие клавиши

- **Insert** — показать/скрыть окно
- **Alt+X** — альтернативный хоткей

## Зависимости

-  — управление окном (overlay поверх всего, без рамки)
-  — глобальные хоткеи
-  — управление состоянием
-  — рендер Markdown в шпаргалках
-  — DeepSeek AI API
-  — хранение данных в AppData
